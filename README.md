<h1 align="center"> Sistema de Cadastro e bonificacão de novos colaboradores </h1>

## descrição

Sistema responsável pelo cadastro de novos colaboradores. No sistema, deverá ser informado o nome do colaborador e seu respectivo salário. O sistema deverá retornar uma mensagem de boas vindas dizendo ao colaborador o seu salário base juntamente com o seu salário bonificado com 15%.
